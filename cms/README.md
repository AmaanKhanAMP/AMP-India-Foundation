# AIF CMS

Admin CMS for AMP India Foundation.

**Full project documentation:** [AIF_CHATBOT_DOCUMENTATION.md](../AIF_CHATBOT_DOCUMENTATION.md)

Historical package README: [`docs/archive/cms_README.md`](../docs/archive/cms_README.md)

## Quick start

```bash
npm install
# set NEXT_PUBLIC_API_URL=http://localhost:5000
npm run dev
```

Default local port: **3001**. Backend API: Flask on **5000**.
