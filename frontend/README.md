## Quick start

```bash
npm install
# set NEXT_PUBLIC_CHAT_API_URL=http://localhost:8000
# set NEXT_PUBLIC_API_URL=http://localhost:5000  (CMS content API)
npm run dev
```

Default port: **3000**.
